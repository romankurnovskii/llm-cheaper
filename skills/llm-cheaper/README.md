# llm-cheaper Agent Skill

This directory contains the agent skill definition for [`llm-cheaper`](https://github.com/romankurnovskii/llm-cheaper).

AI coding assistants and autonomous agents (such as Claude Code, Cursor, Codex, OpenCode, and Antigravity) can load this skill to dynamically query provider pricing and select cost-effective models.

## Structure

- [`SKILL.md`](./SKILL.md) — Self-contained specification, prompt instructions, CLI commands, and JSON schema for agents.
